# Sales Prediction using Machine Learning

## Overview
This project predicts product sales based on advertising expenditure through TV, Radio, and Newspaper.

## Dataset
The dataset contains:
- TV advertising budget
- Radio advertising budget
- Newspaper advertising budget
- Sales (target variable)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Model
Linear Regression

## Evaluation Results
- MAE: 1.27
- MSE: 2.91
- RMSE: 1.71
- R² Score: 90.59%

## Conclusion
The model demonstrates that advertising expenditure, especially TV advertising, can be used to predict sales.
